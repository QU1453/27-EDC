# Resources 资料库

本文件夹用于存放电赛相关的**原始资料**：开发板资料包、芯片/模块手册、原理图、引脚图、示例代码、驱动等。

- 不参与任何工程的编译与烧录，不属于 `Car_Chassis`（STM32）或 `CV_1`（视觉）任一子工程。
- 原则：只读保存，不在本目录内改代码；尽量保留官方压缩包原名，不重复解压占用空间。

## 新增资料约定

1. 外部资料整包放入本目录，文件名保持原样。
2. 在本文件"现有资料"表格中补一行：文件名、大小、一句话说明。
3. 与本项目实际接线/协议相关的结论，写到对应工程的 `modify.md` 或 `docs/`，不要只留在压缩包里。
